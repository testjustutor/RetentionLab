Create them manually in MySQL:\n\n```bash\nmysql -u root -p retention_lab < database/schema.sql\n```\n\nOr use your MySQL client to create tables matching your SQLite schema.\n\n### Issue: \"Duplicate entry\" warnings during seeding\n\n**This is normal!** The `INSERT IGNORE` statement skips existing records.
